# MDBTV

**Фильмы, сериалы и ТВ — на ваших Android-устройствах.**

Смотрите на смартфоне, планшете, телевизоре или ТВ-приставке.

[**Скачать приложение**](https://github.com/JacobPau1/mdb/releases) · [Сайт](https://mdbtv.info/) · [Сообщить об ошибке](https://github.com/JacobPau1/mdb/issues)

## Возможности

- **Фильмы и сериалы.** Просмотр онлайн с выбором доступных озвучек и серий.
- **ТВ-каналы.** Прямой эфир и телепрограмма для поддерживаемых каналов.
- **Плейлист.** Добавляйте фильмы, отдельные серии или целые сезоны, меняйте порядок и смотрите последовательно.
- **История и просмотренное.** Возвращайтесь к открытым фильмам и отслеживайте просмотренные серии.
- **Загрузки.** Следите за скачиванием, управляйте файлами и открывайте загруженное видео во внешнем плеере.
- **Подписки.** Получайте уведомления о новых сериях и изменении качества контента, на который подписаны.
- **Управление пультом.** Навигация по интерфейсу и управление просмотром на Android TV.


## Системные требования

- **Android 6.0 и выше** — API 23+.
- Смартфон, планшет, Android TV или Android-приставка.
- Доступ к интернету для просмотра онлайн.

## Установка

1. Скачайте APK из [последнего релиза](https://github.com/JacobPau1/mdb/releases).
2. Откройте скачанный файл на устройстве.
3. Если Android запросит разрешение, разрешите установку из этого источника для браузера или файлового менеджера, через который открываете APK.
4. Завершите установку и откройте MDBTV.

Для обновления установите новый APK поверх текущего приложения.

Все опубликованные версии доступны в разделе [Releases](https://github.com/JacobPau1/mdb/releases).
